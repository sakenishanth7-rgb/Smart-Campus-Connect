# Smart Campus Connect

Smart Campus Connect is a modern web platform designed to enhance communication, collaboration, and campus engagement among students, faculty, and administrators. The platform provides a centralized hub for announcements, events, academic resources, and campus activities.

## Features

* Campus-wide announcements and notifications
* Event management and participation
* Student and faculty collaboration
* Academic resource sharing
* Responsive and user-friendly interface
* Modern and scalable architecture

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS

## Live Demo

https://smart-campus-connect-dtil.lovable.app/

## Goal

To create a connected campus ecosystem that improves communication, accessibility, and engagement while providing a seamless digital experience for the academic community.
